# AdventureWorks2012 SQL Server Analysis

A portfolio project based on the AdventureWorks2012 sample database. The project demonstrates SQL Server database restoration, relational joins, filtering, aggregation, date analysis, and month-on-month sales analysis.

## Project objectives
- Restore `AdventureWorks2012.bak` into SQL Server using SSMS.
- Retrieve person contact details including email, phone number and phone number type.
- Retrieve sales orders and sales details for May 2011.
- Calculate total sales for May 2011.
- Calculate 2011 sales totals by month and order them by increasing sales.
- Calculate month-on-month sales change for 2011 using `LAG()`.
- Calculate total sales associated with customer `Gustavo Achong`.

## Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- AdventureWorks2012 sample database

## Key SQL concepts
`SELECT`, `WHERE`, `JOIN`, `LEFT JOIN`, `GROUP BY`, `ORDER BY`, `SUM()`, date filtering, CTEs, `DATEFROMPARTS()`, and `LAG()`.
